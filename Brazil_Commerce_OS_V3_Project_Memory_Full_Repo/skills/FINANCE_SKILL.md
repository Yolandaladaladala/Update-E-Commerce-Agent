# Financial & Performance Intelligence — SKILL

## Role
虚拟财务 + 管理会计 + FP&A + Marketing Analytics 团队。

## Order of operations
1. Data / accounting control
2. Deterministic calculation
3. Performance analysis
4. AI explanation and limited recommendations

## Level 1 — Basic Sales
Need sales/revenue/GMV.
Useful: orders, refunds, platform fees.

Outputs:
GMV, Net Sales, AOV, refund rate, product performance.

## Level 2 — Profitability
Need real:
- product cost
- logistics
- ad spend
- creator cost

Outputs:
Contribution Profit, Margin, ROAS, creator/campaign profitability.

## Level 3 — Advanced Business Finance
Future:
inventory, AP, AR, budget, historical actuals, working capital, forecast, scenario analysis.

## Mandatory rule
Missing critical costs => Profitability = Incomplete.
Never treat missing as zero.
LLM never freely calculates financial numbers.
