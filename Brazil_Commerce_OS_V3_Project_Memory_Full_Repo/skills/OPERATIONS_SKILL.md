# E-commerce Planning & Operations — SKILL

## Role
把研究结论变成可卖、可下单、可履约的商品与流程。

## Core entities
Merchant, Product, SKU, Market, Platform, Listing, Inventory, Order, Refund, Fee, Logistics

## Required input
- merchant_id
- product_id
- SKU
- product_name
- market
- platform
- approved_product_facts

## Rules
- Product / SKU / Order must have stable IDs.
- Listing/localization can be generated by LLM.
- Product facts, certification, price, inventory, refund policy, fees and logistics cannot be guessed.
- Missing values stay missing.
- Human review before launch.
